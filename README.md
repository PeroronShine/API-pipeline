# NLP Pipeline: Анализ тональности отзывов

Автоматизированный скрипт для классификации отзывов.
Считывает CSV-файл, отправляет данные в LLM (GigaChat), получает JSON и сохраняет результат.

## Стек
- Python 3.8+
- Pandas (работа с CSV)
- Requests (HTTP запросы)
- GigaChat API (LLM)

## Структура файлов
- `pipeline.py` — основной скрипт пайплайна.
- `reviews.csv` — входные данные (пример отзывов).
- `results.csv` — **результат работы скрипта** (вывод нейросети).
- `.env` — файл конфигурации (хранит API ключ, не загружается в Git).

## Как запустить

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа
1. Создайте файл .env в корне проекта.
2. Вставьте туда свой ключ в формате:
   GIGACHAT_API_KEY=ваш_ключ_от_GigaChat

### Запуск скрипта
```
python pipeline.py
```
Скрипт обработает файл reviews.csv и создаст (или обновит) файл results.csv с анализом каждого отзыва.
